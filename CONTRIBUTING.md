# Contributing

Thank you for looking. MoonShine is built in the open by one owner, with coding agents, and measured as it goes ([`docs/method/`](docs/method/)).

## Issues

Issues are welcome: bugs, questions, ideas. Please never put personal data in an issue: no real task or note titles, names, calendar entries or file paths from your own setup. Describe the shape of the problem with invented examples, as the repository's fixtures do.

## Code contributions

Code contributions need a contributor licence agreement (CLA), because the owner keeps sole copyright so that MoonShine can also ship under other licences later ([ADR-0008](docs/adr/0008-license-and-distribution.md)). No CLA is offered yet, so pull requests from outside the project cannot be merged for now. If you would like to contribute code, open an issue first.
