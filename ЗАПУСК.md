# MoonShine — пульт управления агентами (для Руслана)

> Репо на английском (публичный GitHub). Этот файл — на русском, для тебя, можно держать вне репо.

## Карта документов

- `docs/VISION.md` — зачем, для кого, 5 «работ» (увидеть / понять прогресс / спросить / сделать / импортировать), принципы.
- `docs/ROADMAP.md` — фазы 0–8 с таймбоксами и **гейтами**: See → Plan → Board → iPad (3b) → Ask → Act → Zoom out → (Own, Share по гейтам).
- `docs/ARCHITECTURE.md` — порты и адаптеры, доменная модель.
- `docs/adr/0001–0008` — ключевые решения. Статус `proposed`: прочитай, поправь, переведи в `accepted`.
- `docs/specs/` — пока только фазы 0 и 1. Спеку следующей фазы пишем после двух недель реального использования предыдущей.

## 0. Разовая подготовка (15 мин)

1. Распаковать в `~/WorkProjects/moonshine` → `git init && git add . && git commit -m "chore: kickoff docs"`.
2. `brew install xcodegen`. Добавить `LICENSE` (текст AGPL-3.0 с gnu.org), когда подтвердишь ADR-0008.
3. Публичный репо на GitHub, push.
4. Claude Code — **локально на Mac** (облачный работает на Linux, `xcodebuild` там нет; ядро `MoonShineCore` можно гонять и в облаке).

## 3. Как руководить

- Цикл на каждый слайс: **план → твой OK → код → PR → ревью → строка в method log**.
- Замечания ревью сразу помечай классом: `privacy · wrong-API · tone · over-abstraction · test-gap · hallucinated-property · scope-creep`.
- `/cost` в конце сессии → в колонку токенов.
- Параллельные агенты — только на независимое (например, адаптер Obsidian и JXA-мост), в отдельных worktree.
- Ревьюер-агент на PR параллельно с тобой — ок, но решающее слово твоё, и это тоже пиши в лог.

## 4. Предохранители (твои же правила)

- **Гейты роадмапа не обсуждаются.** Фаза 7 (свои задачи и заметки, iOS) — после 2 месяцев ежедневного использования. Фаза 8 (сервер, App Store, деньги) — после 50+ запросов извне и первого «я бы заплатил» → сразу называешь цену.
- **Не планирование ради планирования.** Если хочется улучшать MoonShine вместо того, чтобы выполнять то, что он показывает, — это паттерн. Метрика пользы: скрипка / AI-ML / наука движутся лучше, чем до приложения.
- **Таймбоксы жёсткие.** Не успел — режем объём по порядку из спеки.
- **Каждое воскресенье:** «есть ли ссылка, которую не стыдно вставить в заявку?»
